# PCAP Network Packet Capture Analysis using Wireshark

## Overview
Performed forensic analysis of captured network traffic to identify suspicious activity, analyze network behavior, and reconstruct network architecture in a simulated enterprise environment.

## Objectives
- Identify malicious or suspicious traffic
- Apply forensic investigation workflow
- Analyze packet-level behavior
- Produce evidence-based reporting

## Tools & Technologies
- Wireshark
- TCP/IP, DNS, HTTP, HTTPS
- Network Forensics Techniques

## Methodology
1. Imported PCAP files into Wireshark
2. Applied protocol and behavioral filters
3. Inspected suspicious packets
4. Reconstructed communication flows
5. Documented findings for reporting

## Key Outcomes
- Detected abnormal network behavior
- Identified suspicious IP communication
- Reconstructed logical network layout

## Documentation
Detailed forensic report available in `/reports`.
